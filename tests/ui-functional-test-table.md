# EasyVibe 界面功能测试表（UT-UI v1，2026-09-30）

> 用法：测试者（人或 agent）以**真实用户视角**执行——不要只勾对错，要像第一次用的人一样思考：
> "我会找这个按钮吗？""这一步顺吗？""这个词看得懂吗？"并在备注列写下真实感受。
> 状态列：✅ 通过 / ❌ 失败 / ⚠️ 通过但体验差 / 💡 有改进想法

环境前提：`./scripts/dev.sh` 已启动（默认挂 hover-client，或逗号分隔多仓库）；浏览器打开 localhost:7100。

## 测试者自由发挥区（必填）

除了上表，测试者必须完成以下"真人任务"：

1. **新手 5 分钟**：假装第一次看到本产品，5 分钟内不做任何提示地探索——你找到了几个功能？哪里卡住了？哪里让你惊喜？
2. **挑刺三连**：找三个你最想骂的地方（布局/文案/路径皆可），说明为什么。
3. **设计挑战**：有没有哪个界面布局你觉得应该推翻重来？画不出图就用文字描述你心中的样子。
4. **路径优化**：选一个常用任务（如"从发现问题到发起修复"），数一数点击次数，给出减少点击的方案。
5. **功能许愿**：作为真实用户，你还想要什么？（不受现有功能约束）
